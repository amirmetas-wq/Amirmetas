# نصب آزمایشی روی Galaxy S25 Ultra

این راهنما برای وقتی است که اجرای GitHub Actions با موفقیت تمام شده و خروجی APK وجود دارد. صفحهٔ تغییرات و اجرای ساخت: https://github.com/amirmetas-wq/Amirmetas/pull/1

1. در GitHub وارد حساب خودت شو و اجرای موفق **Android preview** را باز کن. از بخش **Artifacts**، بستهٔ **hamrah-android-preview** را بگیر.
2. اگر فایل ZIP بود، در برنامهٔ My Files سامسونگ آن را استخراج کن و `app-debug.apk` را باز کن. اگر اندروید اجازهٔ نصب خواست، فقط برای برنامه‌ای که همین فایل را باز می‌کند اجازه بده.
3. برنامهٔ «همراه» را باز کن. در صفحهٔ خانه، دسترسی اعلان‌ها را فعال کن. فعال‌کردن هر زمان‌بندی جداگانه و از صفحهٔ همان قابلیت انجام می‌شود.

## کارهای مهم روزانه

در Samsung Notes، خود یادداشت «کارهای مهم روزانه» را باز کن، Share و خروجی متنی/Text file را انتخاب کن و آن را به «همراه» بفرست. متن را در پیش‌نمایش بررسی و تأیید کن. از صفحهٔ «کارها»، ساعت دلخواه را تعیین و اعلان روزانه را روشن کن؛ دکمهٔ آزمایش اعلان هم وجود دارد.

این متن یک نسخه از یادداشت است. بعد از تغییر یادداشت در Samsung Notes، دوباره آن را به همراه بفرست. روش «انتخاب فایل متنی» تنها تغییرات همان فایل انتخاب‌شده را دوباره می‌خواند و به یادداشت خصوصی سامسونگ متصل نمی‌شود.

## ایمیل

- Yahoo: در حساب Yahoo یک **App password** بساز و آن را فقط داخل همراه وارد کن. «ذخیره و آزمایش اتصال» را بزن. از رمز اصلی حساب استفاده نکن. راهنمای حساب: `YAHOO_SETUP.fa.md`.
- Gmail: پیش از ورود، باید تنظیم **Gmail API / Android OAuth** برای بستهٔ `ir.hamrah.agent` و SHA-1 گواهی همان APK انجام شود. اجازهٔ اعلان یا تقویم جای این مرحله را نمی‌گیرد. راهنمای `GMAIL_SETUP.fa.md` را دنبال کن.
- پس از تأیید اتصال، ساعت گزارش و فاصلهٔ بررسی را در صفحهٔ «ایمیل» تنظیم کن و زمان‌بندی را روشن کن. نسخهٔ محلی گزارش عنوان و گزیدهٔ حداکثر ۳۰ ایمیل اخیر هر حساب در ۴۸ ساعت گذشته را نشان می‌دهد.

## جلسه

در صفحهٔ «جلسه‌ها»، عنوان، تاریخ **میلادی**، ساعت، مدت و فاصلهٔ یادآوری را بده. موقع درخواست، دسترسی تقویم را تأیید و تقویم مقصد را انتخاب کن. جزئیات را قبل از ثبت بررسی کن. جلسه در تقویم انتخابی و فهرست همراه ذخیره می‌شود.

## دستیار هوشمند و حافظه

قابلیت AI اختیاری است و به کلید شخصی و اعتبار OpenAI API نیاز دارد؛ آن را فقط در خود برنامه وارد کن. ثبت دستی جلسه، یادآوری کارها و گزارش اولیهٔ ایمیل به AI وابسته نیستند.

ارسال گزیدهٔ ایمیل‌ها برای خلاصهٔ هوشمند، گزینهٔ رضایت جداگانه دارد و در ابتدا خاموش است. حافظهٔ دستیار متن ترجیحات تأییدشدهٔ توست و می‌توانی آن را ویرایش یا پاک کنی. پیشنهاد جلسه هم قبل از اجرا تأیید می‌خواهد.

## زمان اجرا و به‌روزرسانی

محدودیت باتری سامسونگ، خاموشی یا Force stop می‌تواند اجرا را عقب بیندازد. همراه را از Sleeping/Deep sleeping apps خارج کن و بعد از Force stop دوباره بازش کن. زمان‌بندی این نسخه تضمین دقت دقیقه‌ای ندارد.

APK خروجی فعلی، پیش‌نمایش با امضای Debug است. برای به‌روزرسانی‌های پیوسته و حفظ داده‌ها باید کلید امضا ثابت بماند؛ کلید موقت GitHub Actions در ساخت‌های مختلف ممکن است تغییر کند. قبل از اتکا به این نسخه برای داده‌های بلندمدت، امضای ثابت و خصوصی باید تنظیم شود. کلید خصوصی یا رمزها را در مخزن عمومی یا چت قرار نده.
