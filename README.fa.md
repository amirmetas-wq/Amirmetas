# همراه — پیش‌نمایش کد دستیار اندروید

این بسته کد پروژه است؛ هنوز APK ساخته یا روی گوشی آزمایش نشده است. آزمایش نحو جاوا و منطق زمان‌بندی جای کامپایل اندروید و آزمایش روی Galaxy S25 Ultra را نمی‌گیرد. وضعیت دقیق در `docs/VALIDATION.md` ثبت شده است.

## قابلیت‌های پیاده‌سازی‌شده در کد

- رابط فارسی و راست‌به‌چپ، تنظیم ساعت یادآوری کارها و گزارش روزانهٔ ایمیل از داخل برنامه. زمان‌بندی تا فعال‌کردن کاربر خاموش است.
- دریافت یادداشت «کارهای مهم روزانه» با Share متن از Samsung Notes یا انتخاب فایل متنی. کارهای علامت‌خورده با `[x]`، `☑` یا `✅` در اعلان روزانه حذف می‌شوند.
- اتصال یک Gmail با اجازهٔ رسمی Google و یک Yahoo با App password. گزارش محلی حداکثر ۳۰ ایمیل اخیر هر حساب در ۴۸ ساعت گذشته، از عنوان و گزیدهٔ متن تهیه می‌شود. ایمیل ارسال، حذف یا خوانده‌شده نمی‌شود.
- ثبت جلسه با انتخاب تاریخ، ساعت، تقویم مقصد و فاصلهٔ یادآوری؛ هم رویداد و یادآور تقویم و هم اعلان همراه ایجاد می‌شود. انتخاب‌گر دستی تاریخ میلادی است.
- دستیار متنی اختیاری با OpenAI API برای پیشنهاد جلسه و ذخیرهٔ ترجیحات، با تأیید قبل از ثبت. خلاصهٔ هوشمند ایمیل جداگانه و فقط با فعال‌کردن گزینهٔ رضایت ارسال گزیده‌های ایمیل اجرا می‌شود.
- نگه‌داری رمز برنامهٔ Yahoo و کلید شخصی AI با Android Keystore؛ هیچ کلیدی داخل کد یا APK تعبیه نشده است.

## دسترسی‌هایی که بعد از نصب لازم می‌شوند

1. **اعلان‌ها:** هنگام روشن‌کردن یادآوری‌ها. تنظیمات هر دستهٔ اعلان نیز باید روشن باشد.
2. **خواندن و نوشتن تقویم:** هنگام ثبت اولین جلسه؛ برای انتخاب تقویم مقصد و ساخت رویداد و یادآور.
3. **Gmail فقط‌خواندنی:** ورود در صفحهٔ رسمی Google. پیش از استفاده، Gmail API و OAuth مخصوص بسته و گواهی همین APK باید تنظیم شود؛ راهنمای `docs/GMAIL_SETUP.fa.md`.
4. **Yahoo:** ساخت App password در حساب Yahoo و واردکردن آن فقط در خود برنامه؛ راهنمای `docs/YAHOO_SETUP.fa.md`. اگر Yahoo برای حساب App password ارائه نکند این اتصال فعال نمی‌شود.
5. **یک فایل متنی انتخابی:** فقط در صورت انتخاب این روش؛ برنامه دسترسی همهٔ فایل‌ها را نمی‌گیرد.
6. **اختیاری، کلید شخصی OpenAI API:** فقط برای قابلیت هوش مصنوعی؛ اشتراک ChatGPT جای اعتبار API نیست. درخواست‌ها هزینهٔ API دارند. کلید را در چت نفرستید.

رمز اصلی ایمیل، کد دومرحله‌ای، دسترسی Accessibility، مخاطبان، پیامک و دسترسی همهٔ فایل‌ها درخواست نمی‌شود.

## یادداشت سامسونگ و اجرای پس‌زمینه

«All notes» معمولاً صفحهٔ همهٔ یادداشت‌های Samsung Notes است. برنامه‌های اندروید اجازهٔ عمومی برای خواندن پایگاه خصوصی Samsung Notes ندارند. Share، یک نسخهٔ متنی می‌سازد؛ بعد از تغییر یادداشت باید دوباره Share کنید. انتخاب یک فایل متنی با دسترسی پایدار، امکان خواندن تغییرات همان فایل را فراهم می‌کند؛ این فایل خودبه‌خود به یادداشت اصلی سامسونگ متصل نمی‌شود.

اعلان‌ها با زمان‌بندی غیر‌دقیق اندروید اجرا می‌شوند. خاموشی، Force stop، Doze و محدودیت باتری سامسونگ می‌توانند اجرا را عقب بیندازند. در تنظیمات Samsung، همراه را از Sleeping/Deep sleeping apps خارج کنید؛ پس از Force stop برنامه را دوباره باز کنید. ثبت یادآور در تقویم نیز به برنامه و تنظیمات تقویم وابسته است. این نسخه به سرور دائمی وصل نیست و ساعت اجرای قطعی تضمین نمی‌کند.

## یادگیری و قابلیت جدید

حافظهٔ فعلی متن ترجیحات و اصلاح‌هایی است که خودتان ذخیره یا تأیید می‌کنید. قابل ویرایش و حذف است و در درخواست‌های AI بعدی استفاده می‌شود. این کار آموزش دوبارهٔ مدل، یادگیری خودکار از تمام فعالیت‌های گوشی یا خودنویسی کد نیست. کارهای خارج از قابلیت فعلی به‌عنوان پشتیبانی‌نشده اعلام می‌شوند. قابلیت تازه نیاز به ماژول و به‌روزرسانی امضاشدهٔ برنامه و گاهی مجوز جدید دارد.

## ساخت و ادامهٔ توسعه

راهنمای `docs/BUILD.md` شامل ساخت محلی و گردش کار آمادهٔ GitHub Actions است. هیچ مخزن یا سرویسی از طرف شما ایجاد نشده است. برای نصب و به‌روزرسانی باید ابتدا APK واقعاً کامپایل و امضا شود، سپس روی گوشی آزمایش شود. برای حفظ داده‌ها هنگام به‌روزرسانی، نام بسته و کلید امضا باید ثابت بمانند. حذف برنامه یا پاک‌کردن داده‌ها، حافظه و تنظیمات محلی را پاک می‌کند.
